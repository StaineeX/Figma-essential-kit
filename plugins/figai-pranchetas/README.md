# FIGAI Pranchetas

## Finalidade

Criar uma prancheta com painéis e dobras configuráveis diretamente no Figma.

## Recursos confirmados pelo código

- Define nome, largura, altura, margens e quantidade de dobras.
- Cria um frame com painéis e texto de identificação.
- Valida medidas positivas e margem dentro da área útil.

## Instalar e executar

No Figma Desktop, importe `manifest.json` em **Plugins → Development → Import plugin from manifest…** e execute **FIGAI Pranchetas** pelo mesmo menu.

## Limitações conhecidas

O plugin depende da fonte Inter Regular para o texto criado. O código cria a prancheta no documento atual e não exporta arquivos.

## Dependências

Nenhuma dependência externa declarada; requer Figma Desktop.
